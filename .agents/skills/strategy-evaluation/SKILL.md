# 策略开发与评价

工程根是本文件向上四级目录；先读其 AGENTS.md、[策略与计算产物规范](../../../docs/artifacts.md)、[数据与执行](../../../docs/data-and-execution.md)。按需查[默认指标规范](../../../docs/metrics.md)，不重复装入全部参考材料。

1. 固定问题、规则、参数含义、标的范围、数据要求、信号／成交时点、仓位和费用假设。区分草稿与可运行版本：机制、默认值或执行假设变化保存新策略版本；同一规则换参数生成新运行。
2. 核对真实权限、日历和 DoriBT 实际支持范围。日线做多和现金是默认范围，不默认拥有分钟线、债券、黄金或全部市场规则。缺口明确预检失败或声明简化假设。
3. 执行前保存输入身份、源码及锁文件快照、参数、评价窗口、预热、种子和环境。用原生终端运行工程命令；每个正式数值证据有独立计算记录，失败保留，重试另记。
4. 读取完整账户、持仓、交易、费用和引擎诊断，进行工程校验与必要对账。退出 0、财务结果完整、宿主登记成功是不同事实。不得声称通过尚未实现的指标 profile。
5. 搜索前确定空间、预算与选择规则，保存全部候选、失败和中断范围。记录 train／validation／test 的实际使用；用于选择的窗口不能重新标成全新独立样本外。
6. 依据问题选压力测试、滚动、扰动或蒙卡，保存方法、次数、种子、全体结果与假设；模拟盈利比例不等于未来盈利概率。不强制每项研究跑全套检验或统一打分。
7. 用同窗、同成本结果解释收益、回撤、恢复与代价，保留负面结论与未完成项。回测表现优先使用 DoriBT 自带绘图，其余研究图复用[绘图与导出](../../../docs/charting.md)，保持语义配色。运行封面采用本次计算的图表；策略本身不伪装为某次回测表现。按[宿主兼容](../../../docs/host-compatibility.md)交付规则、运行、证据和阅读入口，必要时按 research-study 流程维护研究和系列。

当前 `example` 是固定合成日线示例与独立演示 profile；真实策略任务不以该示例冒充正式回测，不为贴齐指标表编造输出。
