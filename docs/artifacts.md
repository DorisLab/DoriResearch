# 工程默认产物规范

本工程的领域规范由用户工程维护；宿主接入另见[兼容说明](host-compatibility.md)。Schema 和程序在 backend，正文规范在本文件，财务定义在[指标规范](metrics.md)。定制需同步生成、校验、读取和导出，记录版本与理由，不用改文档冒充程序已经具备能力。

## 研究

研究回答明确问题，保存范围、方法、结论、发现与证据、限制、未决项和可读正文；可以很短，不强制固定章节和空字段。观察、解释、假设分开。负面结果或证据不足是合法结论，不表示任务失败。

可以关联策略、计算、前一研究与系列，也可以没有关联。更正保存前身和新依据，纯解释修改不重算。正文和图表读取实际数据，封面可选，不为填满布局伪造图表。

## 策略

包含可理解规则、运行入口、实际代码／依赖、参数与默认值、数据要求、信号与成交时点、成本、仓位及资产约束。草稿可以不可运行；标为可运行前核对必要输入和程序。

机制、参数含义、默认值、数据要求或执行假设改变生成新策略版本。相同规则选其他参数值创建新计算并保留实际值。历史运行绑定当时代码；业绩属于具体运行，引用代表运行显示实际区间、费用和数据性质，不自动挑最好的一次。

## 计算

默认类型 analysis／backtest／validation／search／robustness，允许明确声明的扩展。一次 Agent 执行可包含多次计算。计算前保存请求、实际参数、输入选择和源码，执行中留日志，结束保存结果和校验。程序生成 ID、时间、哈希与清单，模型组织问题和解释。

输入保存发布／选择身份、字段、范围、预热、日历、调整、可知时点和缺失处置。源码保存实际修改和锁文件，Git 提交号不能代替脏工作区。数据快照按授权保留，派生文件不是另一套市场数据库。

失败保留部分结果和错误；重试另建身份、关联前次。搜索保留候选与选择过程，不只保存赢家。复现分开说明材料可获得、实际复算与容差。完整性校验、复算一致和策略有效是三个不同判断。

工程状态与宿主事实独立：`running/succeeded/failed` 是工程运行入口观察，强制中断可能留下 running；只可报告未确认结束，不补造成功。取消、跨重启进程恢复和正式登记由宿主能力负责。

## 系列

保存原始问题、范围、具体版本的成员及承接关系、当前判断、排除解释、未决项、下一步与状态。一项研究可属于多个系列，不强制每项加入；系列不是用户手工维护的对话主题。

根据证据维护当前认识，不把最新文章自动当总结。改变范围和排除解释说明依据。研究保存成功但系列维护失败分别报告，不回滚已经交付的研究。

## 当前格式与实现范围

| Profile | 可执行内容 | 边界 |
| --- | --- | --- |
| `dorislab.analysis.v1` | 明确来源 CSV 的统计分析；请求、输入、源码／锁快照、环境、结果、报告与摘要清单 | analysis 子集，非回测，无策略或系列占位；校验后可导出并正式登记为 study |
| `dorislab.study.v1` | 任意研究代码、正文及显式证据文件导出、封存与登记；见[研究交付](study-delivery.md) | 校验文件与宿主接入，不自动执行代码或判定研究结论；复算和质量由对应研究负责 |
| `dorislab.etf-momentum.v1` | 本地成品日线、固定池月度正动量、DoriBT 账本与默认指标、独立复算、策略及关联运行登记 | 仅无公司行动区间；成交规则为显式研究假设；详见[回测入口](backtesting.md) |

对其他问题优先扩展工程程序和对应规范。没有实现的 profile 不标通过。完整公司行动／历史规则和通用宿主计算生命周期仍待实现。正式登记、基础阅读与本地文字搜索已接入，命令和兼容边界见宿主兼容说明。

可读正文与结构化证据分别保存。已完成目录不覆盖，修订生成新目录并记录前身；工作代码和临时表可修改。宿主接受后由正式回执指定永久引用，不从目录名猜版本身份。
