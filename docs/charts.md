# 研究正文中的图表

研究、策略和回测结果共用 Markdown 的 `echarts` 组件。它读取纯 JSON ECharts option，或 `{"data":"curve.parquet","option":{...}}`；数据路径相对配置文件，列通过 `dataset` 和 `encode` 引用。准确版本以当前工程 `frontend/package.json` 的 `dependencies.echarts` 为准，本版固定为 6.1.0。需要确认 API 时，先核对该版本的官方文档或本地依赖类型。

## 正文与默认布局

- 默认没有外边框和卡片背景，用留白区分正文与图表。
- 章节标题已经说明用途时，不重复添加图表标题。需要独立标题时使用 `option.title.text`，可选 `subtext` 补充口径；单个普通标题显示在画布外，可换行，右侧为“引用图表”。链接标题及多标题仍使用作者的 ECharts 布局。
- 图注可直接放在图表后的 Markdown 段落，按需注明样本、费用、基准和来源，不重复轴上已经写明的信息。
- 默认网格将轴文字和轴名称纳入边界计算；横轴名称居中，长图例可翻页。窄栏图表可能只有约 340px，避免在轴末端放长句；多个复杂子图优先拆成独立图表。
- 未指定的布局与颜色使用公共默认值；显式网格位置、轴归属、缩放目标、颜色和数值范围保留。复杂自定义布局需要自行核对不同宽度；不要把显式固定像素布局当作自动响应式布局。
- 配置不接受 JavaScript 函数。简单标签使用 ECharts 字符串模板；计算和数据转换在生成附件时完成。阅读历史报告不会重新执行任意图表脚本。

## 数据口径

- 单位与数值一致。若原数据 `0.12` 表示 12%，先生成百分数列 `12`，再使用 `axisLabel.formatter: "{value}%"`；仅添加 `%` 不会乘以 100。保留原始列便于复核，金额和比例不要混在同一数值轴。
- 次数、笔数等整数指标设置 `minInterval: 1`。柱状图通常保留零基线；截断基线会夸大差异。公共 `chartOption` 对整数柱状数据自动使用整数刻度及零基线，显式 ECharts option 仍按作者设置。
- 自然时间跨度使用 `xAxis.type: "time"`，数据中保留日期／时间；逐交易日或分类对比使用 `category`。不要仅因为标签看起来像日期就改变原本的间隔含义。
- 回撤通常使用零以下的百分比曲线，注明负号口径；DoriBT 的原始回撤为正的损失幅度，绘制负向回撤时显式取负。公共样式不会猜测或改写数值符号。

## 配色

研究图表共用 `backend/src/dorislab_research/chart_theme.json`。浅色与深色主题的默认分类色按相同顺序对应，作者显式颜色不被主题替换。语义角色：策略红、基准蓝、超额金、回撤绿、敞口青；策略颜色表示身份，不随单日涨跌翻转。基准推荐虚线，回撤推荐向零线填充的浅绿色区域，避免只靠颜色区分。

普通 ECharts option 不会根据系列名称推断角色；按上述角色选用主题色，或直接使用默认分类色。`frontend/src/charting.ts` 与 Python `dorislab_research.charting` 的可选辅助函数支持既有 `role` 字段。静态导出采用浅色主题；直接调用 DoriBT `result.plot()` 仍使用该库自己的样式。

Python 辅助函数的分类轴保留原始顺序和等距含义，只稀疏显示标签；需要自然时间轴或更复杂排版时可直接使用 Matplotlib。

## 开发验证

`scripts/verify-charts.mjs` 在真实浏览器渲染研究正文，覆盖窄栏／宽栏、深浅主题、大字号、长标题、图例和坐标轴文字，并检查缩放与图例状态。它是开发回归入口，不是产品 Agent 工具。组件测试覆盖显式多网格、数值范围与缩放目标保留；Python 测试实际绘制连续日期并检查相邻标签重叠。

在 `frontend` 安装锁定依赖后运行 `npm run test:charts`。Windows 使用本机 Edge；其他平台先执行 `npx playwright install chromium`。脚本也导出 `verifyCharts(browser)`，可复用隔离桌面 fixture 的 WebView2 连接。截图和几何结果保存在 `target/chart-verification/<时间>/`；只创建合成页面，不连接账号资料库。定向结果和实际验证边界见[本轮记录](validation/charts-2026-10-27.md)。
