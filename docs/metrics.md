# 默认运行指标

定义版本：dorislab.research.metrics.v1。此文随可编辑工程维护，是默认完整回测 profile 的规范。当前已实现 profile 见 [产物规范](artifacts.md)；没有实现的指标必须标为未实现，不能把合成示例的有限输出冒充完整验收。

## 规范归属与定制

默认工程按本文提供完整、可解释的输出。详细口径随工程发布，由 AGENTS.md 指向、Skill 按需读取；系统提示词只保留证据和诚信原则。宿主消费成果导出的标题、文字、入口与引用，不逐项验证这里的财务公式。

用户可要求定制指标、结果结构或评价方法。Agent 同步修改工程定义、程序、检查、页面与导出，保存实际定义和检查版本；不能沿用官方名称却暗改含义，也不能为通过某次检查而删除证据。自定义规范不必原样满足本文每个字段，但须声明差异、保存来源并维持最小宿主接入兼容。

## 1. 按计算目的要求结果

所有运行保留身份、实际输入、代码、环境、状态、结果清单和日志，具体归属由产物契约定义。下表要求成功计算具备什么，不要求失败运行补造缺失结果。

| 运行类型 | 必需结果 | 按问题增加的结果 |
| --- | --- | --- |
| `analysis` 分析 | 问题对应的核心表／数值、样本范围与数量、单位、方法、缺失处置 | 分组、相关性、分布、图表；不强制收益指标 |
| `backtest` 回测 | 账户／净值、回撤、持仓、意图／订单／成交／费用／未成交原因，标准绩效与基准声明 | 月度、分段、交易统计、归因和风险分析 |
| `validation` 验证 | 验证对象、检查方法／版本、期望／实得、容差、逐项状态与证据 | 数值对账、规则检查或统计检验；这些检查类别分别标明 |
| `search` 搜索 | 搜索空间、预算、实际尝试账本、选择规则、入选项和未完成范围 | 多目标、参数敏感性、独立留出评价 |
| `robustness` 稳健性 | 父运行、具体检验方法、变更条件／种子／次数、全体结果与总结 | 成本压力、删样本、滚动、蒙卡、参数扰动、DSR 等 |

一个回测可以另有 search 或 robustness 父／子运行；不因多个页面就重复计算。报告选择核心展示，完整输出仍可查。普通研究不必执行所有稳健性方法，也不按一张固定指标表获得统一分数。

## 2. 指标值、定义与不可计算

默认工程每条 Metric 保存 `metric_id, definition_version, value, unit, status, reason, scope, source_refs, parameters`；字段由工程模型与导出程序维护，模型不逐条手填。

- `scope` 明确运行、评估区间、组合／基准、分组或 train／validation／test 段。
- `status` 为 `computed | undefined | not_applicable | not_computed`。只有 computed 有有限数值；其余 value 为 null 并附原因。
- 必需且适用的指标不能以 not_computed 通过成功 profile；数学无定义可以通过，但必须给原因和相应样本统计。
- 标准比率用小数，金额带币种，计数用整数，时间注明交易日或日历日。显示时再转百分比；不能依靠列名猜单位。
- `definition_version` 和参数包括年化、费用、目标收益、基准、采样和统计方法。相同名称、不同定义不能静默合并。
- 自定义指标使用命名空间并附定义和来源，不能覆写标准名称。

指标出自计算程序，Agent 解释并引用结果。宿主登记只说明文件和接入可用，不认证数值正确。引擎输出与默认口径不同时，工程适配器保留原值、定义和换算；无法可靠换算则分列，不重新贴同名标签。

## 3. 标准日线回测输出

首条正式回测路径为 A 股／ETF、人民币、日线、做多与现金。交易单位、可卖限制、停牌／涨跌停、成交量、价格调整、公司行动、费用与滑点均记录实际规则和引擎支持范围；缺必要信息时按预检失败或声明的简化研究假设处理，不冒充完整市场仿真。

### 3.1 基础表与图

| 输出 | 必需内容 |
| --- | --- |
| 账户与净值 | 时间、现金、持仓市值、总权益、单位净值、收益、费用；包含初始估值点 |
| 回撤与恢复 | 同净值时间轴的回撤、峰谷定位、最长水下期、期末是否仍未恢复 |
| 持仓与暴露 | 日期／标的、数量、市值、权重、现金占比；可核对杠杆和预算 |
| 交易链路 | 策略意图、订单、成交、取消／拒绝／未成交原因及关联身份 |
| 费用 | 佣金、税费等实扣金额；滑点作为成交模型及其影响单独说明，避免重复扣减 |
| 基准 | 基准定义、构造、再平衡、费用／分红／复权口径与同窗曲线；确不适用须说明 |
| 绩效 | 下节标准指标、完整／部分月收益；按条件增加交易统计 |

零成交不是文件缺失：保留有 Schema 的空表、真实账户曲线和零成交计数；依赖交易样本的指标为 undefined 或 not_applicable。缺基准数据时不画零收益假基准；相对表现不可计算并明确限制。

### 3.2 必需标准指标

所有口径基于实际评估区间，预热不计入绩效。令 `V_t` 为扣除实际费用后的单位净值，初始点为 `V_0>0`；发生外部资金流时先按声明的单位化规则处理，不把入金当收益。首版不支持的资金流在请求预检中拒绝。

| 指标 | v1 定义与边界 |
| --- | --- |
| 累计收益 | `V_T / V_0 - 1`，期末未平仓按实际估值计入 |
| 年化收益 | `(V_T / V_0)^(365.25 / 日历天数) - 1`；不足一年仍显示实际区间及短样本提示。天数为零或终值为负时无定义；终值为零是全部损失，值为 -1 |
| 年化波动 | 日收益样本标准差（ddof=1）乘 `sqrt(252)`；至少两个有效日收益 |
| 最大回撤 | `D_t=V_t/max(V_0…V_t)-1`，曲线为非正值，最大回撤指标为 `-min(D_t)` 的非负深度 |
| 恢复／水下期 | 从前高后首个低于前高的估值点到重新达到前高前一估值点的交易日数；期末未恢复标记 censored，不虚构恢复日期；同时可附峰至恢复的日历天数 |
| 夏普 | 日超额收益均值／样本标准差 × `sqrt(252)`；无风险年率须声明，默认假设 0，转换日率为 `(1+rf)^(1/252)-1`；零方差或样本不足时无定义 |
| 索提诺 | 日收益减最低目标日收益的均值／下行偏差 × `sqrt(252)`；下行偏差为全部 n 日中 `min(r_t-target,0)^2` 均值的平方根；默认目标年率 0，记录其日率换算；分母为零时无定义 |
| 最差月收益 | 相邻月末单位净值之比减一；首尾不完整月明确标为部分月，完整月最差值与部分月分别显示；无完整月时标准值为空 |
| 平均／最大仓位 | 日末多头持仓市值／总权益；交易日等权平均和最大值，现金占比可核对；不适用多头语义的扩展另定义 |
| 换手 | 单边等价累计换手：逐日 `0.5 × 当日买卖成交绝对金额之和 / 前一估值点权益` 后求和，包含初建仓；另列实际成交总额，年化换手使用同一实际日历天数 |
| 成交与费用 | 成交笔数、订单数、实扣费用合计及分项；不把订单数、部分成交笔数和完整交易回合数混用 |

默认标准指标列必须存在，但不要求全部在首屏平铺。面向稳健收益问题，优先呈现累计收益、回撤、恢复时间、月度分布、仓位和费用；风险调整收益和交易指标可展开。以上是默认工程的 v1 定义，不声称适用于所有市场；扩展市场或频率另声明 profile。

### 3.3 条件指标和执行语义

有明确交易回合划分时，才计算胜率、平均盈亏比、profit factor 和平均持有期；保存配对方法、费用分摊、未平仓处理和有效回合数。连续组合调仓没有唯一回合定义时，不强制输出看似精确的胜率。

Calmar 等派生比率必须引用已定义的年化收益和回撤深度，分母为零时无定义。不得把累计收益除回撤后直接标成相同年化指标。扩展多空策略分列多头／空头贡献；A 股做多首版无需空头占位列。

期末估值与末尾强制平仓是不同假设。请求中固定是否平仓，输出保留最后持仓和对应成本；比较两种处理另建验证／运行，不能偷偷去掉末尾亏损交易。

基准对照、毛收益与净收益、价格收益与总收益明确区分。主报告默认净收益，毛收益仅作成本诊断；费用翻倍后的结果必须实际重算受影响的交易／现金或声明为近似分析。

## 4. 搜索与候选选择

搜索轮数表示实际探索工作量，不是有效性指标。搜索运行在开始前登记搜索空间、预算、目标指标、方向、约束、评价区间、选择规则和随机种子。人工或 Agent 逐步修改策略同样要保留可追溯的尝试记录，不能只留下最终赢家。

账本区分提出候选数、实际执行数、成功数、失败／取消数、去重后参数组合数和被选择候选。以上计数不等于统计意义的独立试验次数；做 DSR 等调整时，另声明有效试验数量的估计方法。

候选记录至少包括候选 ID、父／批次身份、策略版本、参数摘要、运行引用、完成状态、评价值和选择／淘汰原因。批量向量化执行可用一个受管计算和逐候选表，仍须能复核每个候选的输入和结果，不能为节省文件数丢失失败项。

保存最终选择规则与实际选择，说明是否按验证集排序、是否人工排除候选、是否在看到结果后改了目标。中断搜索保留已完成部分及预算使用，不宣称搜索完全部空间。没有运行搜索时，次数为 not_applicable，不填 0 伪装已经验证。

多项实验横向比较要求共同评价窗口、基准、成本与执行口径。不能统一时分组展示差异，不输出一个无说明的总排名。模型名称、推理强度和执行成本可作来源属性，不据一次任务建立模型能力结论。

## 5. train／validation／test 与信息暴露

只要涉及拟合、选参或候选筛选，就记录分段角色、边界、样本数、有效独立事件数及使用方式。无需训练的固定规则策略可以没有 train；短数据窗口不强行切出三个缺乏样本的分段，也不能因此声称已经完成样本外验证。

结果包含预热、训练、选择和评价范围，窗口标签、特征可知时点、重叠样本、purge／embargo 或其他泄漏处置按实际方法记录。普通随机切分不能自动证明时序独立。

信息暴露记录区分：用于拟合、用于选参、用于事后解释、仅一次最终评价、使用历史未知。反复查看验证集再调整后，它已参与选择；已看过的历史重新运行不能标记为全新独立样本外。自动账本只证明系统记录范围，不能声称知道模型预训练数据或用户在外部看过什么。

「train 有没有 edge」不作为无定义布尔字段。需说明对照、指标、交易成本、估计不确定性与样本支持。「train→valid 落差」保存同口径两个值和差值；改善或恶化本身不等于有效或过拟合结论。评估结论由研究解释，程序提供可复查事实。

免费示例的 2025-01—2026-09 是可用输入目标，不是自动满足长期、独立验证的证据。预热后实际评价区间更短时必须显示。

## 6. 稳健性与统计检验

这些是按问题选择的条件分析，不作为每次回测的固定门槛，也不统一设定夏普、p 值或 DSR 的合格阈值。若用户或研究计划要求某项检验，未执行时明确待完成，不能以省略代替通过。

| 分析 | 必须同时保存 |
| --- | --- |
| 成本／滑点压力 | 原值与变更值、是否完整重算、交易与资金约束变化、同窗结果 |
| 参数扰动 | 邻域或范围、全部组合、基准选择、失败／边界值，不只画最优点 |
| 分年／滚动／删样本 | 窗口边界、重叠关系、每段样本数、删除依据及全部结果 |
| 蒙特卡洛／Bootstrap | 重采样对象（收益、交易或区块）、方法、相关性处理、次数、种子、模拟期限、初始资金、复利／费用／破产和终值定义 |
| 显著性／多重比较 | 原假设、统计量、检验或重采样方法、单／双侧、样本依赖、多重比较处理和实际尝试范围 |
| DSR 等选择偏差调整 | 公式／实现版本、样本长度、分布统计、搜索次数及有效独立试验数假设、输入和输出 |

蒙卡「盈利概率」指声明的模拟分布中终值超过声明阈值的路径比例；中位终值是该分布的中位数。二者绑定假设与模拟期限，不能标成真实未来盈利概率。保存分位数、失败／破产路径处理和抽样误差，不只展示一个百分比。

确定性重排同一组收益在固定复利规则下可能并不改变终值；此类方法不能仅凭路径顺序变化宣称估计出了新的终值分布。方法选择和结果验证应能发现这种退化情形。

## 7. 验证责任与验收

引擎负责执行与账本，研究工程负责默认输出、指标口径和领域 Schema 校验，Rust 校验宿主接入身份、文件和协议。执行退出、领域检查、登记与统计结论分别记录；不能把财务重算塞进页面，也不把正确性寄托给 LLM 自查。

最小检查覆盖：净值／现金／持仓对账、日期对齐、费用不重复扣除、成交与订单关联、回撤由净值派生、零交易、无下行／零波动、短区间、部分月、未恢复回撤、缺基准、搜索中断与次数核对。数值抽样与独立基准使用明确容差。

提供一个实际包含仓位变化和费用的固定输入用例，比镜像实现的指标断言更重要。统计方法检查种子可复算与边界行为，不靠随机输出恰好好看来通过。尚未实现的指标／分析必须保持未实现状态，不能在文档冻结时填入模拟验收结果。
