## 失败与边界

- 初次真实渲染在 489px 页面、18px 字号复现末端日期越界约 22px。补齐首尾刻度展示及内向对齐后，同一断言通过，没有放宽容差或删除断言。
- 首次原生尝试使用当前 release 客户端二进制，测试调试端点未就绪，未执行到图表。改用已有 Debug fixture 构建后通过。此结果证明当前图表源码在真实 WebView2 中的渲染，不代表 release 安装版或正式账号保存／打开链路验收。
- WebView2 使用现有隔离桌面测试宿主，通过 Vite 加载当前生产阅读组件和合成数据。测试关闭自己的页面与进程，用户客户端和数据保持不动。
- 已有 jsdom 外观测试会提示缺少 canvas `getContext`；该环境只承担配置合并断言，真实文字几何由浏览器／WebView2 检查承担。
- 本次为源码提交，Dorislab 发布锁与用户已安装版本未变。启用到客户端需要后续发布接入。
