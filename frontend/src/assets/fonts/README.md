- Regular 400、Light 300、Medium 500、Bold 700、Heavy 800、Black 900；字重读取自各文件的 OS/2 元数据。
- CSS 使用应用内别名 `Dorislab Alibaba Sans`，避免同名系统安装版本覆盖默认资源；界面展示原名 Alibaba Sans。
- 六个文件总计约 579 KB，随 Vite 构建进入应用，不需要系统安装，也不从网络加载。中文继续按字体回退链渲染。
